# **App Name**: OmniRide

## Core Features:

- User Account Management: User profile and authentication to save user's info and booking history.
- Vehicle Selection Interface: Display available vehicle options (car, motorcycle, truck, etc) based on location and user preferences.
- Real-Time Tracking: Real-time map display showing vehicle locations, routes, and estimated arrival times.
- Integrated Payments: Secure and seamless payment integration using Stripe.
- Ratings and Reviews: Allows users to provide feedback and ratings for their rides.
- SMS Notifications: Sends SMS notifications to the user.
- AI-Powered Vehicle Suggestion: Suggest the optimal vehicle choice based on passenger count and estimated cargo volume; also take current traffic conditions into consideration as a tool in reasoning about the best suggestion.
- Set Number of Seats: Allow the user to specify the number of seats required for the ride.
- Ride User Page: First page for ride users includes pickup location, dropoff location, cost of ride, vehicle number, and other ride details.
- Driver/Rider Page: Second page for drivers/riders includes pickup location, dropoff location, and a rider registration page where drivers provide information like driving license details.

## Style Guidelines:

- Primary color: #6699FF (RGB) for a calm, trustworthy, and modern feel. Derived from the core concept of transportation which is often associated with blue.
- Background color: #F0F4FF (RGB) a very light tint of blue provides a clean and open backdrop.
- Accent color: #FF9966 (RGB) for a touch of energy. The orange contrasts with the primary blue for highlighting key elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, for a modern and neutral feel in both headlines and body text.
- Use consistent and easily recognizable icons for vehicle types, navigation, and user actions.
- Clean and intuitive layout with a focus on map integration. Ensure key information (vehicle options, time estimates, payment details) are easily accessible.
- Subtle transitions and animations for vehicle movements on the map, loading states, and user interactions to enhance the user experience.
